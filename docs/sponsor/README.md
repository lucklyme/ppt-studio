# 赞赏码

把收款码图片放在本目录，README 的「支持这个项目」章节会直接展示。

| 文件名 | 说明 |
|---|---|
| `wechat.png` | 微信赞赏码 |
| `alipay.png` | 支付宝收款码 |

建议尺寸 500×500 左右的方形 PNG，白底或透明底均可，单张控制在 200 KB 以内。

图片就位后，把 README 中该区块的 HTML 注释去掉即可显示：

```html
<p align="center">
  <img src="docs/sponsor/wechat.png" alt="微信赞赏" width="220">
  <img src="docs/sponsor/alipay.png" alt="支付宝赞赏" width="220">
</p>
```
