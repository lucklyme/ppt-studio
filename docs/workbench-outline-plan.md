# 工作台、章节编排与部门管理实施计划

已获用户确认。基于现有.NET+JS+WPS，直接实施，不修改部门正式PPT内容。

1. 部门改名与删除：管理员授权；改名保持ID和引用；空部门可删除；company系统部门禁止删除；有关联账号（含停用）、页面、上传文件则409并提示数量。测试编辑越权、重复名、关联阻断、成功删除、审计。
2. OutlineChapter(Id,Title,Summary,PageIds)与ComposeOptions(NumberStyle,TocPageNumbers,PageNumbers)写入方案和生成快照。后台以PageIds+必选规则确定可用集合，验证章节ID/标题长度/重复页/非法页；缺失必选按内容章节自动补入。空章忽略；旧方案兼容。
3. PPT引擎：章序按大纲，章标题和摘要回填，自动序号可数字/中文，目录每4章分页，可显示最终章节起始页。页码可选，替换原生页码占位避免源页序号误留。正文任意文本不自动改写（字段绑定后续）。测试重排、五章目录、空章、原始文字保持。
4. 前端：章节新增/改名/摘要/上移下移/删除空章、跨章拖动或下拉移动、实时目录预览、方案复用保持大纲；页码与编号选项。
5. 首页：角色相关待办（管理员待审；编辑草稿/驳回/即将到期）、本人维护版本记录、本人方案和历史；近期真实PPT缩略图。空状态操作明确，不用公司模板封面作大图。
6. 回归核心/HTTP/UI/WPS，备份后重启。
