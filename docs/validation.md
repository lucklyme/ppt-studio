## 已作出的环境决策

1. 外部npm/NuGet连接被系统拒绝，因此首版使用现有.NET SDK及无外部依赖的前端；代价是需要后续迁移正式架构。
2. 为避免静默破坏版式，不同比例或不同物理尺寸均阻断合成；代价是部门需要使用公司模板尺寸。
3. 使用结构预览并明确标识；不能作为精确视觉或动画保真的验收证据。
4. 审核中的页面暂不接受新版本；代价是部门需先处理审核。
